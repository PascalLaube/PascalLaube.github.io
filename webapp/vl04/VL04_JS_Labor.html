⚡ JS-Labor: Die Hackathon-Seite wird lebendig

VL 04 · JavaScript kompakt · Web-Applikationen · WS 2026/27 · 20 Minuten

So geht's: Arbeitet zu zweit an einem Laptop. Ladet VL 04 · JS-Labor Starter (ZIP) herunter und entpackt es. Darin liegt die Hackathon-Seite aus VL 2, dazu programm.json und app.js. Eure Aufgaben stehen in app.js bei den TODO-Kommentaren. Zu jeder Aufgabe gibt es hier einen Tipp und, ganz eingeklappt, die Lösung.

A · Server starten und Konsole öffnen 3 Min

Im entpackten Ordner einen kleinen Server starten, nicht per Doppelklick öffnen:

python -m http.server 8000
# oder
npx serve
  1. http://localhost:8000 im Browser öffnen, F12, Tab Konsole.
  2. Steht dort app.js ist geladen? Dann läuft alles.
  3. Tippt in die Konsole: document.querySelector("h1").textContent = "Hallo". Was passiert, was passiert nach dem Neuladen?

Bleibt die Seite bei „Programm wird geladen …“ und steht in der Konsole ein CORS-Fehler, habt ihr die Datei direkt geöffnet. Adresszeile prüfen: Sie muss mit http:// beginnen, nicht mit file://.

B · Programm aus programm.json laden 8 Min

Setzt in ladeProgramm() die TODOs B1 bis B3 um. Die Funktion karte() ist schon fertig.

  1. Nach dem Speichern und Neuladen stehen drei Karten auf der Seite, und „Programm wird geladen …“ ist verschwunden.
  2. Network-Tab: Mit welchem Statuscode kommt programm.json? Und beim zweiten Neuladen? (VL 3)
  3. Benennt programm.json kurz um. Was zeigt die Seite jetzt? Benennt die Datei danach zurück.
Tipp

const antwort = await fetch(…), dann antwort.ok prüfen, dann await antwort.json(). Für jeden Punkt: liste.append(karte(punkt)). Am Ende status.remove().

Lösung 
const antwort = await fetch("programm.json");
if (!antwort.ok) {
  throw new Error(`HTTP ${antwort.status}`);
}
const punkte = await antwort.json();
punkte.forEach((punkt) => liste.append(karte(punkt)));
status.remove();

C · Anmeldung prüfen, ohne neu zu laden 7 Min

Setzt die TODOs C1 bis C4 um.

  1. Tippt eine Gmail-Adresse: Das Feld wird rot, darunter steht ein Hinweis.
  2. Mit einer Adresse auf @htwg-konstanz.de und einem Namen ersetzt ein Dank das Formular. Die Seite lädt dabei nicht neu.
  3. Was passiert ohne event.preventDefault()? Probiert es aus und schaut in den Network-Tab.
Tipp

C1: email.value.trim().endsWith(…). C2: email.addEventListener("input", pruefeEmail). C3: event.preventDefault(). C4: document.createElement("p"), className, textContent, form.replaceWith(…).

Lösung 
// C1
const ok = email.value.trim().endsWith("@htwg-konstanz.de");
// C2
email.addEventListener("input", pruefeEmail);
// C3 (erste Zeile im submit-Listener)
event.preventDefault();
// C4
const danke = document.createElement("p");
danke.className = "bestaetigung";
danke.textContent = `Danke, ${name}! Wir melden uns per Mail.`;
form.replaceWith(danke);

Für Schnelle Bonus

  1. Daten statt HTML: Ergänzt in programm.json einen vierten Punkt, etwa {"zeit": "19:00", "titel": "Party", "text": "Pizza für alle"}. Am HTML ändert ihr nichts.
  2. Warum textContent? Setzt einen Titel auf <img src=x onerror=alert(1)>. Was passiert? Und was, wenn ihr in karte() testweise innerHTML statt textContent nutzt? Danach wieder zurückstellen.
  3. Event Loop: Sagt die Reihenfolge voraus und prüft in der Konsole:
    setTimeout(() => console.log("A"), 0); console.log("B"); Promise.resolve().then(() => console.log("C"));
